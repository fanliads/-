# F1 看板视图迭代—页面结构

## 1. 页面层级

| 页面 | 类型 | 说明 |
|---|---|---|
| 看板视图 | 修改现有页面 | 单页双对象、全宽状态看板 |
| 原始需求详情 | 复用现有页面 | 原始需求卡片的完整详情承载页 |
| 产品需求详情 | 复用现有页面 | 产品需求卡片的完整详情承载页 |

## 2. 看板视图

### 2.1 页面标题区

- 标题：“看板视图”。
- 辅助信息：当前筛选结果总数。
- 描述：按状态查看并推进需求。
- 不保留“当前视角 / 总需求数 / 筛选状态”三块大尺寸摘要卡，避免挤占纵向空间。

### 2.2 对象切换区

- 分段控件：[原始需求] [产品需求]。
- 当前对象有明确选中态。
- 切换后更新状态列、筛选字段和卡片结构。
- 从迭代详情进入时自动选中“产品需求”。

### 2.3 工具栏

- 搜索框：编号、标题。
- 筛选按钮：优先级、业务线、负责人。
- 产品需求专属：所属迭代。
- 已选条件标签：逐项删除。
- 操作：清除全部。
- 结果计数。
- 工具栏位于看板上方主内容区，不使用右侧信息区。

### 2.4 状态列区域

- 全宽横向布局，可横向滚动。
- 列头：状态色点、状态名称、卡片数。
- 列体：卡片列表、拖拽放置反馈、空列状态。
- 列宽稳定；选中卡片不改变列宽。
- 卡片很多时列内纵向滚动或按现有分页策略加载。

### 2.5 卡片

#### 通用字段

- 编号、标题。
- 优先级、负责人。

#### 原始需求附加字段

- 业务线、来源。

#### 产品需求附加字段

- 业务线、所属迭代。
- 工作量仅在现有字段有效时展示。

#### 卡片操作

- 拖拽：更改状态。
- 单击：进入独立详情页。
- 更多菜单：仅承载已有权限允许的轻量快捷操作。
- 不呈现长描述、完整字段宫格或“推进判断”面板。

### 2.6 反馈状态

- 页面首次加载：列骨架。
- 空列：显示“暂无需求”，但保留可放置区域。
- 筛选无结果：提示清除筛选。
- 保存中：卡片局部状态。
- 保存失败：回滚并显示错误提示。
- 无权限：统一无权限页面状态。

## 3. 路由与上下文

- 看板路由保存对象类型和可分享的筛选参数。
- 进入详情前保存横向/纵向滚动位置。
- 从详情返回时恢复看板上下文，并重新校准已变更卡片。
- 从迭代详情进入时携带迭代 ID，不复制一套迭代专属看板页面。

## 4. 明确禁止

- 右侧常驻详情栏。
- 右侧辅助判断或信息汇总栏。
- 点击卡片后压缩看板主区域的分栏布局。
- 原始需求与产品需求混排。
