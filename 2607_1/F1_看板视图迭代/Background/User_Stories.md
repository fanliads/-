# F1 看板视图迭代—用户故事

## US-F1-01 切换需求对象

**作为** 有看板访问权限的用户，  
**我希望** 在同一页面切换原始需求和产品需求，  
**以便于** 使用一致的方式查看两类需求，而不必寻找两个入口。

### 验收标准

1. 页面提供“原始需求 / 产品需求”切换控件，并明确显示当前对象。
2. 切换后加载对应对象的状态列、卡片字段和筛选项。
3. 两类需求不混排在同一列中。
4. 切换对象时不出现右侧常驻信息栏。
5. 刷新页面后恢复最近一次对象类型；无记录时使用产品既定默认值。

## US-F1-02 按状态查看全量工作

**作为** 产品经理或产品负责人，  
**我希望** 在全宽看板上按状态查看需求，  
**以便于** 快速识别工作分布和需要推进的事项。

### 验收标准

1. 每个有效状态对应一列，列头显示状态名称和当前卡片数。
2. 空列保持可见并显示空状态，不因无卡片消失。
3. 状态列超出可用宽度时支持横向滚动。
4. 卡片至少显示编号、标题、优先级和负责人。
5. 原始需求卡片补充业务线和来源；产品需求卡片补充所属迭代。
6. 选中或操作卡片前后，看板主区域宽度保持一致。

## US-F1-03 筛选和搜索

**作为** 需要聚焦特定工作的用户，  
**我希望** 按关键词和业务字段筛选卡片，  
**以便于** 快速缩小当前工作范围。

### 验收标准

1. 支持按编号或标题搜索。
2. 支持优先级、业务线和负责人筛选。
3. 产品需求看板支持所属迭代筛选；原始需求不展示无意义的迭代筛选。
4. 多个筛选条件按“且”关系组合。
5. 页面展示已生效条件和结果数量，并提供一键清除。
6. 无结果时显示可恢复的空结果状态，不清空用户筛选。

## US-F1-04 任意拖拽状态

**作为** 具备状态编辑权限的用户，  
**我希望** 将卡片拖到任意状态列，  
**以便于** 直接推进或纠正需求状态。

### 验收标准

1. 卡片可从当前状态拖到任意其他状态列，不限制前后顺序。
2. 拖拽过程中明确显示源列、目标列和可放置反馈。
3. 放置成功后更新需求状态、列计数和卡片位置。
4. 保存失败时卡片回滚到原列，并展示失败原因。
5. 拖回原列或放置到无效区域时不提交更新。
6. 无编辑权限的用户不显示可拖拽态，权限规则本期不改变。

## US-F1-05 进入详情并返回现场

**作为** 需要查看完整需求信息的用户，  
**我希望** 从卡片进入独立详情页并返回原工作现场，  
**以便于** 深入查看后继续处理原来的看板范围。

### 验收标准

1. 点击原始需求卡片进入原始需求详情页；点击产品需求卡片进入产品需求详情页。
2. 看板内不展开右侧常驻详情或判断面板。
3. 返回看板后恢复对象类型、搜索、筛选、横向滚动和纵向滚动位置。
4. 详情中修改的状态、负责人或优先级在返回后同步到卡片。
5. 若修改导致卡片不再符合筛选条件，卡片从结果中移除并更新数量。

## US-F1-06 从迭代进入看板

**作为** 产品经理，  
**我希望** 从迭代进入已经限定范围的产品需求看板，  
**以便于** 直接跟踪该迭代执行情况。

### 验收标准

1. 从迭代入口进入时默认切换为产品需求对象。
2. 自动应用当前迭代筛选，并显示明显的筛选标签。
3. 用户可清除迭代筛选查看全部产品需求。
4. 返回迭代详情时恢复原迭代上下文。

## US-F1-07 处理加载和异常

**作为** 看板用户，  
**我希望** 系统明确反馈加载、空数据和保存异常，  
**以便于** 判断当前状态并继续操作。

### 验收标准

1. 首次加载显示与列结构匹配的骨架状态。
2. 全局加载失败显示重试入口。
3. 单次状态保存失败只回滚受影响卡片，不刷新整个看板。
4. 无访问权限时显示统一无权限结果，不泄露卡片信息。
