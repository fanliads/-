# F2 迭代管理优化—业务流程

## 1. 流程逻辑

产品经理继续从现有入口创建或编辑迭代。周期设置以真实起止日期为核心，单周和双周只负责快速带出日期。系统即时校验并计算周期天数，保存后所有迭代引用统一使用真实日期。

## 2. 创建或编辑迭代周期

```mermaid
flowchart LR
    subgraph P["产品经理"]
        P1["进入现有迭代管理"]
        P2["新建或编辑迭代"]
        P3{"如何设置周期？"}
        P4["选择单周或双周预设"]
        P5["直接选择任意起止日期"]
        P6["确认并保存"]
    end

    subgraph I["迭代管理业务"]
        I1["加载现有字段与权限"]
        I2["按开始日期带出 7 天或 14 天区间"]
        I3["接收真实起止日期"]
        I4["计算周期天数"]
        I5{"日期与现有必填项合法？"}
        I6["提示字段错误并保留输入"]
        I7["保存真实起止日期"]
        I8["同步列表、详情、选择器与看板上下文"]
    end

    P1 --> P2 --> I1 --> P3
    P3 -->|快捷预设| P4 --> I2 --> I3
    P3 -->|自定义| P5 --> I3
    I3 --> I4 --> P6 --> I5
    I5 -->|否| I6 --> P3
    I5 -->|是| I7 --> I8
```

## 3. 历史兼容流程

```mermaid
flowchart TD
    H1["读取历史迭代"] --> H2{"存在合法起止日期？"}
    H2 -->|是| H3["以真实日期展示并计算天数"]
    H2 -->|否| H4["按现有兼容规则提示数据异常"]
    H3 --> H5["历史周期枚举仅作兼容读取"]
    H5 --> H6["编辑时允许改为任意合法日期"]
```

## 4. 业务规则

- 日期是周期的唯一事实来源。
- 单周/双周是快捷预设，不是持久化限制。
- 本期不新增临时迭代类型、权限或审批。
- 所有引用迭代周期的页面统一显示真实起止日期。
