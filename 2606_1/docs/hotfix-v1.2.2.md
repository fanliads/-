# v1.2.2 Hotfix

日期：2026-07-23

## 修复内容

生产环境通过 HTTP 访问时，浏览器不保证提供 `crypto.randomUUID()`。产品需求创建入口在弹窗打开前生成防重请求标识，原实现因此抛出运行时异常，表现为顶部“新建产品需求”、分组“+”和拆分创建点击无响应。

本版本统一改用兼容的请求标识生成逻辑：优先使用标准 UUID；不可用时使用浏览器加密随机值；极端兼容场景使用时间戳随机串。防重语义保持不变。

## 验收

在 `http://47.96.71.133/product-pool` 验证：

1. 顶部“新建产品需求”可打开弹窗。
2. Todo、Active 分组“+”可打开弹窗并携带正确目标状态。
3. 原始需求拆分创建可打开弹窗。
4. 创建成功后新需求进入目标分组，刷新后仍存在。
