# 需求中枢 v1.2.0 发布说明

- 迭代：2607_2
- 构建日期：2026-07-22
- 基线提交：`c17dc53f8ef10bc66756bdaf83d4074c78140cba`
- 数据库版本：Flyway V19

## 本次交付

1. 我的工作
   - 收敛为待办指标、任务列表与聚焦详情三层结构。
   - 支持待处理/已处理切换、搜索、手动刷新、任务优先级与完成后自动定位下一项。
   - 统一加载、空状态、错误重试和响应式布局。

2. 产品需求创建
   - 修复顶部与分组内创建的目标状态、关闭确认、错误保留和新记录定位。
   - 增加标题、优先级、状态、URL、业务线、迭代、处理人和父需求的前后端契约校验。
   - 使用 `clientRequestId` 保证重复提交幂等。

3. 外部原始需求提报
   - `/external-submit` 支持匿名提交、草稿保留、隐私确认、移动端单列和受理凭证。
   - 外部记录带来源、渠道、联系人、公司/客户、身份与提交时间，并进入待判定。
   - 提供运行时二维码及 PNG/SVG 下载；可用 `VITE_EXTERNAL_SUBMIT_URL` 指定生产完整地址。
   - 增加输入白名单、URL 安全校验、幂等和每来源每分钟 10 次的应用侧限流兜底。

4. 统一需求 Peek 与样式修复
   - 原始需求池和产品需求池统一行点击预览、前后导航、轻量编辑、关系跳转与追溯信息。
   - 统一选择器图标、状态/优先级表达、列表密度、焦点态和常见页面的遗留样式。

5. 发布安全
   - Axios 升级至 1.18.x，并锁定安全版 `form-data` 传递依赖。
   - `npm audit --omit=dev` 生产依赖审计结果为 0 个已知漏洞。

## 部署注意

- 升级前备份数据库；启动后 Flyway 会自动执行 `V19__external_submission_receipt.sql`。
- 后端要求 Java 17、MySQL 8、Redis 7。
- 生产必须配置 `DB_PASS` 与高强度 `JWT_SECRET`。
- 应用内限流是单实例兜底；多实例生产部署仍应在网关配置全局限流。
- 正式上线前应按发布 SOP 提交代码、创建 `v1.2.0` tag，再从该 tag 部署。
