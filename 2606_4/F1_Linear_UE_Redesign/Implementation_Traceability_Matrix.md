## 4. 验收门禁

- `Pending Decision` 全部关闭后，才允许开始代码整改。
- `Gap` 全部关闭后，才允许进入 UAT。
- `Partial` 必须有用例和证据后才能标记为 `Implemented`。
- `Implemented` 只有通过产品、测试和业务验收后才能标记为 `Accepted`。
